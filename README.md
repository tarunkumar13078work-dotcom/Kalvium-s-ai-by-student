# Kalvium's AI Assistant 🤖

**Kalvium's AI Assistant** is a professional-grade chatbot application providing instant answers to questions about college, Kalvium platform, and programming basics. Built with modern web technologies and featuring a stunning UI/UX.

---

## ✨ Features

- ✅ **Modern Professional UI** with glassmorphism design and smooth animations
- ✅ **Dark/Light Theme Toggle** with seamless transitions
- ✅ **Smart FAQ Search** with real-time filtering
- ✅ **Enhanced Chat Experience** with avatars, timestamps, and typing indicators
- ✅ **Voice Controls** for text-to-speech responses
- ✅ **Fully Responsive** mobile-optimized design
- ✅ **50+ Pre-loaded Q&A** across 3 categories
- ✅ **Zero Dependencies** - pure HTML, CSS, and JavaScript
- ✅ **Privacy-First** - all processing happens locally in your browser

---

## 🚀 Quick Start

### Option 1: Run Locally (Recommended)

```bash
# Clone the repository
git clone https://github.com/tarunkumar13078work-dotcom/Kalvium-s-ai-by-student.git
cd Kalvium-s-ai-by-student/kalviums-ai

# Start a local web server using Python
python3 -m http.server 8080

# Open in your browser
# Navigate to: http://localhost:8080/index.html
```

### Option 2: Direct File Opening

Simply open `kalviums-ai/index.html` in your web browser. Note: Some features work best with a local server.

### Option 3: Deploy Online

Deploy to GitHub Pages, Netlify, or Vercel for free! See [SETUP.md](SETUP.md) for detailed instructions.

## 🎯 How to Use

1. **Browse FAQs**: Click categories in the sidebar to explore questions
2. **Search**: Use the search box to filter FAQs by keyword
3. **Ask Questions**: Type your question in the chat input and press Enter
4. **Theme Toggle**: Switch between dark and light themes
5. **Voice Control**: Enable/disable text-to-speech responses
6. **Clear Chat**: Reset conversation history anytime
